# MERIDIAN-HR-ANALYTICS
HR analytics project analyzing employee turnover, salary, performance, absenteeism and workforce risk using SQL, Excel and Power BI.
# Project Overview
The Meridian HR Analytics Project is an exploratory HR analytics project designed to analyze employee workforce data and identify factors associated with employee turnover, salary, performance, absenteeism, and workforce risk.
The project demonstrates the use of SQL, Microsoft Excel, and Power BI to transform raw HR data into meaningful business insights and recommendations.
# Business Problem
Organizations need to understand why employees leave, how compensation and performance vary across departments, and which employees or groups may present higher workforce risk.
The objective of this project is to analyze the available HR data and provide data-driven insights that can support better workforce planning, employee retention, compensation decisions, and HR management.
# Objectives
The analysis focuses on:

Analyzing employee turnover

Examining salary distribution across employees and departments

Investigating employee performance

Analyzing absenteeism patterns

Identifying relationships between salary, performance, and absenteeism

Examining workforce risk

Comparing HR metrics across departments and employee groups

Developing an interactive Power BI dashboard

Providing data-driven HR recommendations
# Tools Used
SQL Server – data cleaning, transformation, aggregation, and analysis

Microsoft Excel – statistical analysis and hypothesis testing

Power BI – interactive dashboard and data visualization

Microsoft Word – documentation and final analytical report
